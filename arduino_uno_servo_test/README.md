# Arduino Uno 舵机独立验证

此程序用于验证舵机、电源和信号线，不包含蓝牙功能，也不能直接使用 ESP32-C3 的网页前端。Arduino Uno 本身没有 BLE；它通过 USB 串口接收测试命令。

## 接线

| 舵机线 | 连接位置 |
| --- | --- |
| 信号线（橙色/黄色） | Arduino Uno `D9` |
| 电源正极（红色） | 独立稳定的 5 V 电源正极 |
| 地线（棕色/黑色） | 外部 5 V 电源负极，并与 Uno `GND` 共地 |

不要用 Uno 的 `5V` 引脚给舵机供电，除非确认该舵机电流很小且 USB 电源可以承受。

## 烧录与测试

1. 在 Arduino IDE 选择 **Arduino Uno** 和对应端口，烧录 `arduino_uno_servo_test.ino`。
2. 打开串口监视器，波特率设为 `115200`，行尾选择“换行”。
3. 输入下列任一命令：

   ```text
   ANGLE:60
   STATUS
   TEST
   ```

`TEST` 会以 30°步进从 0°扫到 180°再返回。D9 预期为 50 Hz 脉冲，0°约 500 µs、60°约 1133 µs、180°约 2400 µs。

## 判断结果

- Uno 测试可驱动舵机：舵机和供电大概率正常，应继续检查 ESP32-C3 的 GPIO5、板卡走线与测量点。
- Uno 同样无扭力：优先检查外部 5 V 电源、电源负极与 Uno GND 共地、舵机本体及三根线的顺序。
