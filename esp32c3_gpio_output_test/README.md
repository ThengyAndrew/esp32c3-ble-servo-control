# ESP32-C3 SuperMini GPIO 输出自检

此程序用示波器快速确认 ESP32-C3 SuperMini 上可用 GPIO 是否能实际输出 PWM，不依赖 USB 串口或蓝牙。

## 使用方法

1. **先断开舵机信号线**，避免外部电路影响测量。
2. 在 Arduino IDE 中选择实际的 ESP32-C3 板型，烧录 `esp32c3_gpio_output_test.ino`。
3. 示波器地夹接板卡 `GND`，探头尖端依次接待测 GPIO。
4. 设置 DC 耦合、约 `1 V/div`、`5 ms/div`，上升沿触发、约 `1.5 V` 触发电平。
5. 复位后程序按下表循环；每个 GPIO 测试 6 秒，随后所有测试脚拉低 3 秒并从头开始。

| 顺序 | GPIO | 说明 |
| --- | --- | --- |
| 1 | GPIO1 | 候选通用输出 |
| 2 | GPIO3 | 候选通用输出 |
| 3 | GPIO4 | 推荐作为 GPIO5 的替代测试脚 |
| 4 | GPIO5 | 当前舵机信号脚 |
| 5 | GPIO6 | 候选通用输出 |
| 6 | GPIO7 | 候选通用输出 |
| 7 | GPIO10 | 候选通用输出 |

正常引脚会显示 **50 Hz、50% 占空比、0–3.3 V** 的方波：周期 20 ms，高电平约 10 ms。没有方波或恒定高/低的引脚应避免作为舵机信号输出。

## 不测试的引脚

- GPIO2、GPIO8、GPIO9：可能参与启动配置或板载外设，不用于此快速测试。
- GPIO18、GPIO19：原生 USB 功能相关，不测试。
- GPIO20、GPIO21：常用于 UART，保留不测。
- GPIO11–GPIO17：与模块 Flash 相关，不可用作普通 GPIO。

测试完成后重新烧录舵机固件，并将 `SERVO_PIN` 改为已验证有正常方波的 GPIO。若 GPIO4 正常，可将它作为优先替代脚。
