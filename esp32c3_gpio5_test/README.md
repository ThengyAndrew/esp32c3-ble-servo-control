# ESP32-C3 GPIO5 单独测试

烧录 `esp32c3_gpio5_test.ino` 前，请断开舵机信号线；示波器地夹接 ESP32 `GND`，探头接实际的 `GPIO5` 引脚。

程序自动重复三个阶段：

| 阶段 | 时长 | 预期波形 |
| --- | --- | --- |
| 1 | 6 秒 | 50 Hz PWM；每 20 ms 一次 3.3 V、1.5 ms 宽高脉冲 |
| 2 | 2 秒 | 稳定 0 V |
| 3 | 2 秒 | 稳定 3.3 V |

示波器建议：DC 耦合、`1 V/div`、`5 ms/div`、上升沿触发、约 `1.5 V` 触发电平。

判断：

- 三阶段均符合预期：GPIO5 物理输出正常，回到舵机问题应检查外部接线或 3.3 V 逻辑电平兼容性。
- 阶段 2 不能到 0 V：GPIO5 被外部电路拉高、测点错误，或引脚损坏。
- 阶段 3 有高电平、但阶段 1 没有 PWM：LEDC 绑定或固件环境异常。
- 三阶段都无变化：测到的不是 GPIO5、探头地未共地，或 GPIO5 已损坏。
